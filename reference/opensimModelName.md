# Get OpenSim Model Name

Get OpenSim Model Name

## Usage

``` r
opensimModelName(model)
```

## Arguments

- model:

  A `PhysioOpenSimModel` external pointer.

## Value

Character scalar model name.

## Examples

``` r
if (FALSE) { # \dontrun{
model <- opensimLoadModel("gait2392.osim")
opensimModelName(model)
} # }
```
