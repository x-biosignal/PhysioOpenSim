# Changelog

## PhysioOpenSim 0.1.3

### New features

- [`opensimTemplatePath()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimTemplatePath.md)
  returns the path of a bundled tool setup-template XML (`"ik"`, `"id"`,
  `"so"`, `"cmc"`, `"rra"`, `"analyze"`, `"generic"`), for use as the
  `template_file` argument of the `opensimWrite*SetupFromTemplate()`
  writers. The templates now ship in `inst/extdata/` (production
  location) rather than `inst/testdata/`.

## PhysioOpenSim 0.1.2

### Bug fixes

- Fixed a non-portable assertion in the OpenSim parity test
  (`test-opensim-parity.R`) that broke the Windows binary builds. The
  setup writer normalizes output paths via
  `normalizePath(mustWork = FALSE)`, which leaves a non-existent
  relative path unchanged on Linux/macOS but absolutizes it on Windows;
  the test now matches the `<output_gen_force_file>` tag by basename so
  it passes on all platforms. No change to package behaviour.

## PhysioOpenSim 0.1.1

### Validation

- Added an OpenSim parity fixture and test (VAL-06). PhysioOpenSim is a
  thin wrapper whose native model parser and CLI tools require an
  OpenSim-enabled build, so a fully OpenSim-free numeric parity is
  impossible; the new always-running check validates the pure-R setup
  writer against real OpenSim: OpenSim’s `InverseDynamicsTool` loads a
  PhysioOpenSim-generated ID setup and reads its numeric fields
  (`time_range`, lowpass) back exactly (recorded in the bundled
  reference). A bundled real model (`inst/extdata/arm26.osim`, from
  opensim-models) plus its OpenSim summary now back the native-parser
  parity on OpenSim-enabled builds, replacing the `PHYSIO_OPENSIM_MODEL`
  env var. Generated by `data-raw/opensim_reference.{R,py}` (OpenSim
  4.6).

## PhysioOpenSim 0.1.0

Initial release as a standalone package in the x-biosignal
(PhysioExperiment) ecosystem. PhysioOpenSim provides a native OpenSim
C++ bridge for R via Rcpp, exposing model-level operations and full-tool
execution to support biomechanics workflows. OpenSim linkage is optional
at build time; when OpenSim is not detected, the package still installs
and OpenSim-dependent calls fail with informative runtime errors.

### New Features

- Build and availability introspection so downstream code can adapt to
  the local environment:
  - [`opensimAvailable()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimAvailable.md)
    reports whether the package was compiled with OpenSim headers and
    libraries linked, and
    [`opensimBuildConfig()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimBuildConfig.md)
    returns the detection method and compilation status.
  - [`opensimCLIPath()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimCLIPath.md)
    resolves the `opensim-cmd` executable (via the argument, the
    `OPENSIM_CLI` environment variable, or `PATH`) and
    [`opensimCLIAvailable()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimCLIAvailable.md)
    checks resolvability without raising an error.
- Native OpenSim model handles backed by C++ external pointers:
  - [`opensimLoadModel()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimLoadModel.md)
    loads an `.osim` model into a `PhysioOpenSimModel` handle, with
    [`opensimModelInitialize()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimModelInitialize.md)
    and
    [`opensimModelIsInitialized()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimModelIsInitialized.md)
    managing the system state.
  - [`opensimModelSummary()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimModelSummary.md)
    returns structural metadata (body, joint, marker, muscle, and
    coordinate counts plus total mass) from a file path or a loaded
    handle, and
    [`opensimModelComponents()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimModelComponents.md)
    lists the corresponding component names.
  - [`opensimModelName()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimModelName.md),
    [`opensimSetModelName()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimSetModelName.md),
    [`opensimFinalizeConnections()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimFinalizeConnections.md),
    and
    [`opensimSaveModel()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimSaveModel.md)
    inspect, rename, finalize connections on, and serialize a model back
    to XML.
- Tool execution with a dual native/CLI backend selected via the
  `execution` argument (`"auto"`, `"native"`, or `"cli"`):
  - [`opensimRunTool()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunTool.md)
    runs any tool setup XML, returning a structured result with
    execution mode, status, captured `stdout`/`stderr`, and elapsed
    time, and supporting a working directory, extra CLI arguments, a
    timeout, and optional fail-on-error.
  - Tool-specific wrappers
    [`opensimRunIK()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunIK.md),
    [`opensimRunID()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunID.md),
    [`opensimRunSO()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunSO.md),
    [`opensimRunAnalyze()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunAnalyze.md),
    [`opensimRunCMC()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunCMC.md),
    and
    [`opensimRunRRA()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimRunRRA.md)
    cover inverse kinematics, inverse dynamics, static optimization,
    analysis, computed muscle control, and the residual reduction
    algorithm.
- Setup XML templating that fills tag values in an existing OpenSim
  template:
  - [`opensimWriteToolSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteToolSetupFromTemplate.md)
    performs tag replacement with strict or permissive handling of
    missing tags and reports applied and missing tags.
  - Convenience wrappers
    [`opensimWriteIKSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteIKSetupFromTemplate.md),
    [`opensimWriteIDSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteIDSetupFromTemplate.md),
    [`opensimWriteSOSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteSOSetupFromTemplate.md),
    [`opensimWriteAnalyzeSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteAnalyzeSetupFromTemplate.md),
    [`opensimWriteRRASetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteRRASetupFromTemplate.md),
    and
    [`opensimWriteCMCSetupFromTemplate()`](https://x-biosignal.github.io/PhysioOpenSim/reference/opensimWriteCMCSetupFromTemplate.md)
    normalize model, motion, marker, and loads paths and accept an
    optional time range and results directory for each tool.
